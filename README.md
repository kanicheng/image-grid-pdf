# 工程照片整理排版工具 · Image Grid PDF

純前端網頁工具：**一次上傳數十張工程／施工現場照片 → 自動裁切成統一大小、整齊排列 → 加上標題、日期、每張照片的日期浮水印與描述 → 產出單一 A4 PDF**。

不需後端、不上傳任何圖片到伺服器，所有處理都在瀏覽器本機完成，隱私安全。

🔗 線上使用：<https://kanicheng.github.io/image-grid-pdf/>

## 功能

- 📤 一次選取或拖曳數十張圖片
- 🔲 自動排列成網格（欄／列數可調，預設 2 欄 × 3 列，每頁 6 張）
- ✂️ 統一尺寸：**裁切填滿**（整齊一致）或 **完整顯示**（保留全圖）
- 🏷️ 左上標題（含選填副標題）、右下日期，**每頁皆相同**
- 🔁 拖曳縮圖即可調整排列順序（支援滑鼠與觸控）
- 🧭 直式 / 橫式 A4
- 🔠 完整支援中文標題與檔名（文字以高解析度向量化方式嵌入，不會亂碼）
- 📄 超過一頁自動分頁，最後輸出成**單一 PDF**
- 💾 版面設定本地記憶：同一台電腦會記住欄列數、邊界、間距、填滿方式等設定（標題／副標題／日期不記憶，每次重來；可一鍵「重設」）
- 🔒 100% 在瀏覽器執行，圖片不外傳
- 📱 響應式，手機也能用

## 使用方式

1. 開啟網站
2. 輸入標題與日期
3. 上傳圖片，必要時拖曳調整順序
4. 視需要調整欄列數、填滿方式、是否顯示標籤
5. 按「產出 PDF」下載

## 進階設定

- **頁面邊界 / 圖片間距**（mm）
- **輸出畫質**（DPI，越高越清晰、檔案越大）
- **圖片外加細框線**

## 技術

- 原生 HTML / CSS / JavaScript，無建置流程
- [jsPDF](https://github.com/parallax/jsPDF) 產生 PDF
- `createImageBitmap({ imageOrientation: 'from-image' })` 自動校正手機照片 EXIF 方向
- 標題／日期／標籤以 Canvas 繪製後嵌入 PDF，徹底解決 jsPDF 內建字型不支援中文的問題
- 圖片於產出時逐張解碼、繪製後即時釋放，避免大量圖片造成記憶體爆量

## 本機開發

直接用瀏覽器開啟 `index.html` 即可；或起一個簡單伺服器：

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

## 部署（GitHub Pages）

本專案為純靜態檔案，推送到 `main` 後於 repo 的 **Settings → Pages** 選擇 `Deploy from a branch` → `main` / `root` 即可。
